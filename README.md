# Easy云课堂 · 极简移动版 (iOS Safari)

专为 **iOS Safari** 打造的 [Easy云课堂](https://www.easyketang.com/) 轻量级移动端界面重构脚本（Userscript）。免部署服务器、不接管账号密码，打开即用，解决移动端看课界面拥挤、退出视频丢失目录滚动进度、播放器交互受限等痛点。

## ✨ 核心特性

- **全账号全课程自动拉取**：登录后自动并发获取账号下全部课程并按学期分组（当前学期置顶），支持课程名、教师与学期搜索；兼容实验课与普通理论课目录结构。
- **三级原生手感导航**：`我的课程 → 章节/实验目录 → 课前/课中/课后资源`，弹窗播放视频不销毁底层列表 DOM，关闭后完整保留目录滚动位置，并随时可一键切回「原网页」。
- **iOS 原生视频播放体验**：直接调用 iOS Safari 原生 HLS 播放引擎，支持 `1.0x / 1.25x / 1.5x / 1.75x / 2.0x` 记忆倍速、原生全屏、画中画（PiP）、弹窗内上下节直切及本地断点续播。
- **讲义快捷查阅**：PDF / PPT 等讲义链接支持新标签页直接打开预览或保存至 iPhone「文件」App（启用 `noopener,noreferrer` 安全跳转）。
- **授权视频本地保存**：支持对具备离线保存权限的标准视频流进行本地无损封装为普通 MP4（支持保存前音画预览、保存至「文件」App 及系统分享），不处理任何 DRM 或私有加密。
- **隐私与登录态保护**：零持久化 Token（仅在页面内存中临时使用），自动屏蔽官网落地页与登录页，退出登录或切换账号时即时销毁会话与缓存。

## 📱 安装与使用指南（iPhone / iPad）

### 1. 安装扩展并确认脚本目录
1. 在 App Store 免费安装 **[Userscripts](https://apps.apple.com/app/userscripts/id1463298887)**。
2. 打开 **Userscripts** App，查看当前绑定的脚本目录（新版会自动设置默认目录，也可以点击 **Set Userscripts Directory** 自定义一个文件夹，例如 `我的 iPhone / Userscripts` 或 `iCloud 云盘 / Userscripts`）。

### 2. 开启 Safari 扩展权限
打开系统 **设置 → App → Safari 浏览器 → 扩展 → Userscripts**，开启扩展，并将 `easyketang.com`（或“所有网站”）的访问权限设为 **允许**。

### 3. 下载脚本并放入目标文件夹
由于 iOS 版 Userscripts 面板不支持手动新建脚本，「文件」App 也无法直接新建 `.js` 文件，请直接下载现成的 `.user.js` 文件并移入目录：

1. 前往本仓库的 [Releases](https://github.com/<61mo>/easyketang-safari-lite/releases) 页面，下载附件中的 `easyketang-safari-lite.user.js`。
2. 打开 iPhone 的 **「文件」** App，在下载目录找到 `easyketang-safari-lite.user.js`，将其 **移动或存储** 到第 1 步中 Userscripts 指定的目标文件夹内（确保文件后缀保持为 `.user.js`，未被系统改成 `.txt`）。
   - *备选方式*：如果第 1 步选的是 `iCloud 云盘` 目录，也可以在电脑上下载脚本后直接拖入对应的 iCloud 文件夹等待同步；或者在 Safari 中直接打开该脚本的 GitHub Raw 链接，点击地址栏的 Userscripts 扩展图标按提示一键安装。

### 4. 开启「请求桌面网站」并验证加载
1. 使用 Safari 打开 `https://www.easyketang.com`。
2. 点击地址栏左侧图标 → **网站设置** → 开启 **请求桌面网站**（只需设置一次，用于绕过原站移动端拦截页）。
3. 点击地址栏左侧图标 → **Userscripts**，确认列表中已经出现 **「Easy云课堂·极简移动版 (iOS Safari)」** 且处于启用状态，然后刷新网页。

### 5. 开始使用
在原网页正常登录账号并进入工作台后，右下角会自动出现 **「📱 极简模式」** 悬浮按钮，点击即可进入极简移动界面。

> **如何更新脚本**：下载新版 `easyketang-safari-lite.user.js` 并替换目标文件夹中的同名旧文件，刷新网页即可生效（已保存的倍速与播放断点不会丢失）。

## ⚠️ 使用须知与限制

- **仅适配 iOS Safari**：视频播放深度依赖 Safari 原生 HLS 与 WebKit 接口，暂未针对桌面浏览器或 Android 浏览器做专门适配。
- **不上报官方学习进度**：本脚本为纯本地只读增强，**不会**计入平台的视频观看时长和学习进度。如课程考核需要计入官方播放进度、完成测验或提交实验报告，请点击右上角 **「原网页」** 切回官方界面操作（或使用微信 「Easy 云课堂」 小程序）。
- **本地视频下载限制**：
  - 仅支持 H.264 + AAC 编码的普通 MP4 或标准点播 HLS 流，不支持 DRM、私有加密或直播流。
  - 受移动端浏览器内存限制，单文件上限为 `512 MiB`（超过 `200 MiB` 时 iOS 内存压力较大，下载期间请保持 Safari 前台运行且勿切换视频）。

## 🔒 隐私与安全说明

- **无账号凭证持久化**：脚本永不将登录 Token 或账号信息写入 `localStorage` / `sessionStorage`，并在启动时清理早期测试版可能遗留的旧键。
- **最小化本地存储**：`localStorage` 仅保存个人偏好与本地阅读状态（播放倍速、上次课程 ID、上次观看视频 ID、最近 100 条播放秒数断点）。
- **网络请求透明**：所有课程与资源请求仅直连 `cloud-api.easyketang.com` 官方接口，无任何第三方统计、埋点或中转服务器。
- **外部依赖按需加载**：仅当用户主动点击下载 HLS 视频时，脚本才会向 jsDelivr CDN 拉取固定版本的无损封装库 [`mediabunny@1.66.0`](https://github.com/Vanilagy/mediabunny)（不携带 Cookie 与 `Referer`，代码中预留 `DL_MEDIA_LIB_SHA256` 常量可供自行开启 SHA-256 完整性强制校验）。
